# BizFlow

Production-quality SaaS web application.

## Phase 1

Project foundation is in place: Next.js 15 (App Router), TypeScript, React 19, Tailwind CSS, and Supabase client helpers for later SSR work.

Copy `.env.example` to `.env.local` and fill in values when you are ready to connect Supabase. Do not commit secrets.

```bash
npm install
npm run dev
```
