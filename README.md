# BizFlow

Multi-tenant SaaS platform for local businesses.

## Target Businesses

- Gyms
- Salons
- Repair shops
- Clinics
- Service businesses

## Core Features

- Authentication
- Multi-tenancy
- Customer management
- Lead management
- Follow-ups
- Invoices
- Payments
- WhatsApp notifications
- Dashboard
- Reports
- Staff management

## Technology

- Next.js
- TypeScript
- Supabase
- PostgreSQL
- Tailwind CSS
- GitHub
